## 二、四步

### 第 1 步：早上真的收到

- **做什么**：把第 1 天正常过完 → 进屋睡觉 → 进入第 2 天早上。
- **看什么**：聊天列表里出现**刘易斯**的一条新消息；内容应当围绕
  「第一晚」和「你爷爷」（`direction` 指定的两个点）。
- **SMAPI 控制台应当出现**：
  `[StardewAI.Morning] 刘易斯（day2-lewis）早上发来一条消息`
- **算失败**：没收到 / 收到了但内容跑题（比如开始讲镇务、念职务、问「你有什么打算」——
  这三条都是 `boundaries` 明令禁止的）。

### 第 2 步：F8 真的置顶带标记

- **做什么**：按 **F8** 打开聊天界面。
- **看什么**：刘易斯这条**置顶**，且带**未读标记**。
- **算失败**：没置顶 / 没有未读标记 / 列表里根本没有这一条。

### 第 3 步：点进去真的清掉

- **做什么**：点开这条消息，读完关掉；再重新打开 F8 列表。
- **看什么**：未读标记消失，且**不会**再变回未读。
- **算失败**：标记还在 / 关掉又出现（说明 `unreadMorningByNpc` 没被写回）。

### 第 4 步：第二天真的不再发

- **做什么**：再过一天（第 3 天早上）。
- **看什么**：**不再**收到 `day2-lewis` 这一条。
- **原理**：`ModEntry.cs` 发送前查 `client.HasFiredMorningScenario(plan.ScenarioId)`
  → 发成功后 `MarkMorningScenarioFired`；记录随聊天档案存取。
- **算失败**：第 3 天又收到同一条（去重没生效）。
  注意 ㉟ 的取舍：**判据落在 scenarioId 而不是天数** ——
  所以「第 3 天没收到」是正确的，**不能**用「天数过了就发」来解释。

## 三、复位 / 重测

去重记录**不落独立文件**，而是随**存档的 modData** 存取
（`ChatHistoryArchive`：`FiredScenarios` + `UnreadMorningByNpc`）。

重测有两条路：

1. **换一份没跑过的存档副本**（最干净，推荐）—— ㉟ 复制 test3 时踩过一个坑：
   `ChatHistoryArchive.SaveIdFromFolderName` 取文件夹名 `_` **之后**那一段当存档标识，
   所以复制存档**必须换掉文件夹名里的 ID**，否则两份档共用一份聊天记录、互相污染。
2. 或者清掉存档 modData 里对应的 `FiredScenarios` 条目（会一并丢掉聊天记录，谨慎）。
