# Kimi vs DeepSeek：角色风格模仿度对照 — 2026-09-24

## 一、结论摘要

用户问「kimi 和 ds 哪个对角色风格的模仿效果更好」。**答案是各有胜负，而且偏差方向相反**——
不存在一方全面更好。

| 指标 | 赢家 | 读数 |
|---|---|---|
| 原文复述率 | **双方都 ≈0** | Kimi 146 轮 2 次（1.4%）、DeepSeek 0 次 |
| 单角色风格距离 | Kimi 5 / DeepSeek 3 | 平均 **0.977 vs 0.996**（几乎打平） |
| **句子节奏**（句长、逗号） | **Kimi 8/8 全胜** | 原文 8–12 字 / 0.25–0.44 逗号 |
| **语气词克制** | **DeepSeek 8/8 全胜** | Kimi 最多超原文 4.6 倍 |
| **角色区分度** | **DeepSeek 18/28 对** | 原文 0.404 / Kimi 0.615 / DS 0.373 |

### 一句话结论

**Kimi 的句子更像游戏对白（短句、少逗号），但她让所有角色都变成同一种结巴
（「呃……」「嗯……」过量），角色之间被夸大甚至串味。
DeepSeek 的语气克制、角色差异保留得更好，但句子系统性偏长
（13–21 字 vs 原文 8–12 字），读起来像书面语而不像对白。**

## 二、⚠ 数据不对称（读任何数字前必须先看这一节）

| | Kimi | DeepSeek |
|---|---|---|
| 来源 | 本轮实跑 `.tmp/topic-probe/verbatim-*.json` | `artifacts/character-quality-eval/` 09-11~09-17 历史批次 |
| 路径 | `/api/dialogue/test`（**游戏端**，`compactPrompt=true`） | 评测路径（`naturalMode=true`，多 4 张评测卡） |
| 阶段 | **stranger**（hearts=0） | dating / married / friend / acquaintance / close |
| 每角色条数 | 10（Sophia 30） | 53～72 |
| 采样时间 | 2026-09-24（Kimi-K2.5） | 2026-09-11 ~ 09-17（deepseek-chat） |

**路径和阶段都不同，所以这不是严格 A/B，只是「同角色、不同模型」的倾向性证据。**

两个方向的偏差风险：
- **阶段**：stranger 阶段角色更拘谨 → 可能让 Kimi 显得比实际更结巴
- **路径**：评测路径 prompt 更大 → 可能让 DeepSeek 显得比实际更啰嗦

**但 `len_mean` 与 `filler_rate` 都是 8/8 全胜的一致方向**，这种整齐度不像抽样噪声。

## 三、方法

### 风格指纹（6 维）

| 维度 | 含义 |
|---|---|
| `len_mean` | 平均句长（CJK 字数）—— 说话节奏 |
| `ellipsis_rate` | 每 100 字省略号数 —— 犹豫/停顿 |
| `filler_rate` | 每 100 字语气词数（嗯呃哦啊唉呀哎诶嘿哈唔嘛呢吧） |
| `question_rate` | 疑问句占比 |
| `excl_rate` | 每 100 字感叹号数 |
| `comma_per_sent` | 平均每句逗号数 —— 长句/短句倾向 |

**距离** = 各维「相对差」的均方根（相对差 = |a−b| / max(|原文|, 0.5)），
让量纲不同的维度可以并置。距离 0 = 完全一致。

**基准是角色自己的原文库**（`styleSamples`，按 `npcId` 过滤），不是别的模型。
所以「距离更小」直接意味着「更像这个角色本人」。

### 原文复述率

8-gram 命中角色原文库的比例（`n=6/8/12` 三档同报，见 `report-verbatim-rate-2026-09-24.md`）。

### 角色区分度

同一模型内部，角色两两之间的指纹距离，与**原文的角色间距**对照。
只有当模型输出的间距**接近**原文间距时，才说明它既让每个角色像自己、
又没有把角色说成一锅粥。

### 但逐维是压倒性的

| 维度 | Kimi 更近 | DeepSeek 更近 | 方向 |
|---|---|---|---|
| `len_mean`（句长） | **8 / 8** | 0 | Kimi 全胜 |

**8/8 的整齐度远超抽样噪声**，这是本报告最可信的部分。

**DeepSeek 的句长是原文的 1.5～2.5 倍，无一例外。** 对游戏对白来说这是硬伤——
原文句长 8～12 字是被 UI 和节奏约束出来的。

### Kimi 的语气词是系统性问题

| 角色 | 原文 | Kimi | 倍数 | DeepSeek |
|---|---|---|---|---|
| Sebastian | 1.51 | **6.98** | **4.6×** | 1.33 |
| Shane | 2.30 | **8.53** | **3.7×** | 2.13 |
| Elliott | 0.95 | **4.43** | **4.7×** | 0.90 |
| Sophia | 2.74 | 3.00 | 1.1× | 1.31 |
| Sam | 1.80 | 3.59 | 2.0× | 0.86 |

Kimi 让每个角色都带上「呃……」「嗯……」，而且**与角色本身是否爱用语气词无关**——
Elliott 原文只有 0.95（几乎不用），Kimi 给了 4.43。
**这正是她角色区分度变差的直接原因**（见下节）。

### 两个模型都不用的感叹号

原文感叹号率 0.31～4.25（Sophia 高达 4.25、Sam 2.49），
而 **Kimi 全部 8 个角色都是 0.00**，DeepSeek 也只有 0.00～0.03。

**两个模型都在压平原作的热情表达。** 这是一个与模型选择无关的独立问题。

## 六、角色区分度：DeepSeek 更好，但两者偏差方向相反

| | 角色两两距离（28 对） | | |
|---|---|---|---|
| **原文（基准）** | 中位 0.404 | 均值 0.593 | max 2.357 |
| **Kimi** | 中位 **0.615**（+52%） | 均值 0.945 | max 3.891 |
| **DeepSeek** | 中位 **0.373**（−8%） | 均值 0.451 | max 1.391 |

**逐对与原文间距比较：Kimi 10 对 / DeepSeek 18 对。**

- **Kimi 把角色差异夸大**：`Elliott ↔ Wizard` 原文 0.333 → Kimi **1.826**（5.5 倍）
- **DeepSeek 把角色差异压平**：`Sam ↔ Sebastian` 原文 1.780 → DS **0.395**（1/4）

两者都没保住原文的最大间距 `Sophia ↔ Wizard = 2.357`
（Kimi 1.584、DeepSeek 0.719），**DeepSeek 压得更狠**。

### 与第五节联读

Kimi 的语气词过量（所有角色都「呃……」）本该**降低**区分度，
但她的距离反而更大——说明**其他维度的夸张抵消了它**：

```
Kimi 最像的 3 对：Elliott↔Sophia 0.329、Elliott↔Shane 0.331、Elliott↔Sebastian 0.353
  → 全部围绕 Elliott（他的语气词被抬到 4.43，与 Sophia 的结巴撞车）
```

**所以 Kimi 的「区分度大」不全是好事**：一部分来自把 Elliott 说成了 Sophia 那种结巴，
在**整体方差**上拉开了距离，但**具体到角色归属**是错的。

## 七、给选择的建议

**若只能用一个，取决于你更在意哪件事：**

| 你在意 | 选 | 理由 |
|---|---|---|
| **句子读起来像游戏对白** | **Kimi** | 句长/逗号 8/8 命中，DeepSeek 长 1.5–2.5 倍 |
| **角色不串味、语气不吵** | **DeepSeek** | 语气词 8/8 更准，区分度 18/28 |
| **响应速度** | **Kimi 略优** | 中位 1.8 s（DS 2.3 s） |
| **上游稳定性** | 相同 | 抖动率都是 9%～27% |

**但更值得做的是修 Kimi 的语气词问题**——因为：

1. 句长是**硬约束**（UI 与节奏），DS 的 1.5–2.5 倍很难靠 prompt 修
2. 语气词是**软问题**（只要压制「呃/嗯」的生成），且 Kimi 在其余 5 维表现更好
3. 压住语气词后，Kimi 的区分度问题大概率一并缓解

**⚠ 另一件与模型无关的事**：两者都不用感叹号，而原文用得不少。
这是项目 prompt 层的独立缺口，换模型不会解决。

## 九、方法论

1. **「哪个模型更好」常常是个假问题。** 两个模型在 8 个角色上 5:3，
   平均距离 0.977 vs 0.996——若只报这个数字，结论是「打平」，
   而真实情况是**两边错得不一样**，可修性也完全不同。**必须下钻到维度。**

2. **8/8 和 5/3 的可信度差一个量级。** n=8 上 5:3 是噪声，
   但一个指标在 8 个独立角色上全部同向，几乎不可能是偶然。
   报「几个角色更近」时要把 8/8 和 5/3 分开说。

3. **基准要选角色自己的原文，不是另一个模型。** 用「A 比 B 像不像 C」的三角比较，
   可以避免把「两个模型都错」误读成「一个对一个错」。

4. **「区分度更大」不一定更好。** Kimi 的距离更大，但最像的 3 对全围绕 Elliott——
   她把 Elliott 说成了 Sophia 式的结巴，在方差上拉开了距离，在归属上是错的。
   **方向对了才算对，量大了不算。**

5. **历史工件是免费的第二组实验。** 这项对照没有额外花一次云端请求——
   DeepSeek 侧的 569 条回复全部来自 `artifacts/` 里 09-11~09-17 的既有批次。
   **在跑新实验前先问「这个问题以前的数据能不能答」。**
