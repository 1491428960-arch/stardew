# 方向 A 实施与验证：把「回答玩家的问题」翻转为「生成这个角色此刻会说的话」

- 日期：2026-09-28
- 范围：`bridge/src/stardew_ai_bridge/prompts.py` 任务定义类文案（23 处）+ 4 个测试文件断言同步
- 云端请求：12（A-v1）+ 12（A-v2）= **24 条**，累计 243 → **267**
- 关联：`docs/report-perspective-baseline-2026-09-27.md`（定标报告，方向 A 的提出依据）

---

## 一句话结论

**任务类型翻转成立，但必须同时把「态度」锚回「台词」这个载体。**

A 的第一版（只翻转任务定义）让三个角色的病征全部消失，却把格式违规从 0% 推到 **58.3%** —— 线上这些会被 `format_stage_direction` 拦成兜底回复，等于净负收益。补上「态度由台词说出来、不要用旁白」后，**收益全保留、违规回到 0%、字数回到 33.7**（原版 33）。

## 一、动机（来自定标报告的收敛证据）

定标（`report-perspective-baseline-2026-09-27.md`）发现：三个「不贴」的角色偏离方向各不相同，但**三条偏离都指向同一件事** ——

| 角色 | 你判断 | 实测偏离 | 病征 |
|---|---|---|---|
| 刘易斯 | 不贴 | 自我态 −23.7pp、文学腔 +64pp | 散文腔、不表态 |
| 艾芙琳 | 不贴 | 反问 +26.9pp | 只反问、不分享自己 |
| 皮埃尔 | 不贴 | 自我态 −28.6pp、字数 0.35× | 冷淡、无生意人温度 |
| 亚历克斯 | 可接受但不一致 | −9.9 / +8.1 | 长句才有文学腔 |

**共同底层缺口不是「语气」，是「模型在回应玩家，不在扮演角色」**：它在答问，所以没有自己的立场（自我态低）、没有自己的近况（反问替代分享）、也没有自己的性格（皮埃尔不推销）。

此前 96 请求诊断独立得出同一结论：**原版对白里根本没有「回答玩家问题」这个任务。**

两条独立证据线收敛 ⇒ 方向 A：把 `player_input` 从「必须回答的问题」降级为背景，任务变成「为这个角色生成他此刻会说的话」。

## 二、改了什么

### 2.1 任务定义文案（`prompts.py`，共 23 处）

只在**模型本轮真正看到的卡**上改。三轮迭代：

**第一轮（低阶段 6 卡 13 处）** —— 本次验证样本走的是 4 心 `acquaintance` + `compactPrompt`，注入 19 张卡：

| 卡 | 改动 |
|---|---|
| `safety_rules` | 「直接回应玩家当前的一件事」→「以当前角色自己的立场和态度接住玩家当前的一件事——他在说话，不是在答题」 |
| `turn_plan`（compact `answer_only` / `answer_plus_detail` / `anchor` 等） | 「直接回答当前一件事」→「用这个角色自己的态度接住当前一件事」 |
| `stage_execution_card` | 「直接接住玩家的意思」→「先落这个角色自己的立场或态度」；「表达预算：直接回答后最多追加一个角色化动作」→「表达预算：角色化的态度或反应是主句」 |
| `voice_execution_card` | 「先按当前关系阶段和玩家输入作答」→「用这个角色自己的说法开口，玩家输入是接话的由头」 |
| `final_role_voice_contract` | 「先直接回答当前话题」→「先说这个角色此刻会说的话」 |
| `post_history_voice_guard` | 「直接回应并自然推进」→「用这个角色自己的态度接住并自然推进」 |

**第二轮（高阶段 6 处 + `conversation_lead` 3 处）** —— 探针升到 `dating` 10 心后发现**探针 stage 太低会漏卡**：

- `conversation_lead`（**只在高阶段注入**）：「普通 chat 的回复要先回答当前输入（直接回答玩家当前输入）」→「先落这个角色自己的态度或反应」；「直接回答后最多追加一个角色化动作」→「角色化的态度或反应是主句」。**这是线上最直接的任务定义，第一轮完全漏掉了。**
- `affection_priority_final`（L4169/L4182）：「优先接住当前话题并直接回答」／「先回答玩家已经给出的选项」→ 改为「用角色自己的态度接住…」／「先接住…」
- `voice_variation`（L5160）：「先回答内容」→「先落角色自己的态度或反应」
- `turn_plan` 非 compact 版（L478/484/496）

**第三轮（4 处，修副作用）** —— 见 §四：

| 位置 | 改动 |
|---|---|
| `stage_execution_card` 短/长路径 | 「先落这个角色自己的立场或态度，再让玩家的话被自然接住」→「**先让这个角色自己开口表态**，再接住玩家的话」 |
| `stage_execution_card` 表达预算 | 「角色化的态度或反应是主句」→「**角色自己的态度或反应就写在台词里，不要用旁白**」 |
| `conversation_lead` | 同上 |

### 2.2 刻意没动的

- **长度指令四套互相打架**（`safety_rules`「1–3 句 15–80 字」vs `voice_execution_card`「最多二十出头」vs `responseShape`「先用 1 句…再补 1 句」）—— 保持单变量，留给下一轮。
- **`topic` 路径**（找话题、无玩家输入）—— 与 A 的目标无关。宽 grep 核对了 `prompts.py` 里全部含「回答」的 50 余行，逐条判定归属。
- **`_BEHAVIOR_GUIDANCE`、`_TURN_PLAN_INSTRUCTIONS`（非 compact）中未注入的部分** —— 本轮不注入即不改。
- **`persona_core.responseRules`**（角色数据，44 个角色）—— 风险是只改 prompt 会像 B 案那样拿不到新锚点。

### 2.3 测试同步

断言共同步 **13 处**，跨 4 个文件：`test_prompts.py`（含长度守卫 4420 → 4460，并注明增量来源）、`test_topic_intent_card_contract.py`（含 2 处 `not in` —— 旧串消失后会退化成恒真的假断言，一并改指新串）。

**全量 `bridge/tests`：4303 passed**，与改动前基线一致。

### 4.2 逐角色（A-v2 实际输出）

**刘易斯**（改前是「有股让人犯懒的劲儿」这类散文腔）

**皮埃尔**（改前冷淡：「明白。有需要就直接告诉我。」）
> ...哦。那店里刚到了一批春季种子，要不要看看？

→ **市侩 + 热情都在**：被追问就戒备（「我就听不懂了」），但每轮都往生意上带（种子上新、二十袋防风草、库存核对）。**这正是你描述的「比较市侩，有点热情」。**

**艾芙琳**（改前只反问：「下次你想换什么花样？」）
> 啊，那便好。我今早刚剪了几枝玫瑰，正想学着做果酱，只是眼睛比从前花些，看不清糖晶化的点了。
> 以前是我妈妈教我的，她总说糖要慢慢熬，急不得。我现在轮到教Alex了，只是那孩子心浮，站不住。
> 少放点儿也好，现代人都讲究这个。只是糖不够，果胶结不起来，熬出来稀稀拉拉的。

**亚历克斯**（改前 12 条里只有 2 条长句带文学腔）
> 哦，知道就好。我正打算去海滩那边投几球，天气这么敞亮，不动动可惜。
> ……谁说的？
> 嘿，夹克上这些小星星可还在呢，货真价实。

→ 短句、直、口语（「……谁说的？」5 字）。

### 4.3 关键发现：A-v1 的副作用与根因

A-v1 的 **58.3% 格式违规**全部集中在 Pierre（3/3）、Evelyn（3/3）、Alex（1/3）—— **正是三个「不贴」的角色**，Lewis 0 违规。

| 类型 | A-v1 | 实例 |
|---|---|---|
| 括号旁白 | 25% | 皮埃尔：「……嗯。（继续手里的活儿，没抬头）你要是有什么需要的…」 |
| 占位符幻觉 | 25% | 艾芙琳：「春天**(arr[1])**的风吹得花儿**(arr[0])**都精神了」 |
| 场景头 + Markdown | 8.3% | 亚历克斯：「`**Alex** — *acquaintance* — 晴天上午，镇上` 嘿……谁说我放弃了？」 |

**根因**：`stage_execution_card` 里那句禁令「只输出对白文字，禁止动作旁白，包括括号、星号或其他舞台说明和环境描写」**一直都在**，位置就在改动处之前。失效的原因不是禁令缺失，而是**我把具体行为指令（「直接回答玩家当前的一件事」）换成了抽象意图指令（「先落这个角色自己的立场或态度」）** —— 禁令压不住一个更晚、更抽象的要求，模型转而**用旁白来"落实"态度**。同一机制也解释了场景头与占位符：模型开始「表演场景」，于是把 `storyState.relationshipStage`（`acquaintance`）和场景字段拼成了舞台提示。

**验证过占位符不是素材问题**：`arr[` 在 19 张卡里 0 命中、在 `data/generated/**/*.json` 里 0 命中、在艾芙琳的 `speechEvidence` 里 0 命中 —— **是模型自己编的**（`speech_evidence` 的 instruction 里恰好提到过「占位符」这个词）。

**修法是澄清载体、不是加禁令**：把「态度」锚回「台词」（「先让这个角色自己**开口表态**」「角色自己的态度或反应**就写在台词里**」），收益全留、违规归零。

## 五、还没做的

1. **文学腔残余 8.3%**（刘易斯「疲惫是最好的枕头」）—— 可接受，但比喻是否属于他的声音可再论。
2. **长度仍偏高**：33.7 vs 原版 33（改前 31.8）。且长度指令四套互相打架**未动**（单变量纪律），模型取最宽的一套 —— 这是刘易斯改前 54 字（原版 36.7）的直接原因，下一轮应优先。
3. **角色名未本地化**：艾芙琳输出「教 **Alex** 了」，中文语境应为「亚历克斯」。
4. **`local` 链路复读退化**（Sophia 同一句重复 10 次）—— 独立功能缺陷线。
5. **高阶段未验证**：本轮只覆盖 `acquaintance`。`conversation_lead` / `affection_priority_final` 已按同一原则改完并过了单测，但没有真实云端对照。
6. **`persona_core.responseRules`**（角色数据侧）仍是「先回答小镇事务或玩家的问题」，44 个角色——prompt 侧改完后角色数据是否还构成反向拉力，未测。
