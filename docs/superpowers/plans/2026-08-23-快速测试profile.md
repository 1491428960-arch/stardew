**目标：** 添加一个安全、可复现的 PowerShell 启动器，把当前构建的 `StardewAI.NPC` 同步到独立快速测试目录，并通过 SMAPI `--mods-path` 启动最小 Mod 集合。

**技术栈：** PowerShell 7、SMAPI `--mods-path`、Pester 不作为依赖；测试使用 PowerShell 原生断言和临时目录。
