# 聊天记录滚动查看设计

## 目标

聊天菜单保留当前会话的全部消息，用户可以在聊天区滚动查看历史，不再因为固定可见条数导致新回复被旧气泡遮住。

## 交互

- 鼠标滚轮在聊天菜单中按消息块上下移动；向上查看历史，向下回到新消息。
- `PageUp` / `PageDown` 提供键盘快捷滚动，`Home` / `End` 分别跳到最旧和最新位置。
- 聊天区右侧显示原生风格滚动条；点击滚动条轨道可跳转。
- 新消息抵达时自动回到底部；用户主动查看历史后不会被后台回复强制拉回，下一次新消息抵达才恢复底部跟随。

## 数据与布局

- `ChatInputMenu.messages` 不再按 24 条截断；只要菜单存在，消息全部保留。
- 每次绘制根据游戏字体测量文本、计算气泡高度和可见起始消息索引；只绘制当前滚动窗口，避免无裁剪的气泡越界。
- 最新位置由“从末尾向前能容纳的消息”计算，滚动位置在有效范围内夹紧。

## 测试与验证

- 纯规则测试覆盖滚动位置夹紧、方向移动和最新位置优先。
- 运行 SMAPI 全量测试，重新同步 FastTest profile，核对源 DLL/profile DLL SHA-256 与 SMAPI 实际加载路径。
