# 聊天菜单标题可读性设计

## 目标

移除聊天菜单左上角与背景/边框容易混淆的标题和状态文字，保留右侧 NPC 资料卡作为唯一的 NPC 身份展示位置。

## 现状与问题

`ChatInputMenu.DrawHeader` 当前在对话框 header 左上角绘制“和 NPC 聊聊”和好感度文字。真实引擎截图显示，标题靠近金色九宫格边框，像素字体与背景颜色相近，阅读时容易粘连。

## 方案

- 删除 `DrawHeader` 中的标题和状态行绘制；
- 保留 `DrawProfile` 中的 NPC 肖像、显示名和好感度，资料卡成为唯一稳定的 NPC 身份入口；
- 不改变 `ChatLayoutRules` 的坐标、对话气泡、输入框和按钮布局，避免引入新的碰撞问题；
- 不删除 header 区域，保留既有布局高度，避免影响消息和输入区域的纵向位置。

## 成功标准

1. 代码中不再绘制左上角“和 … 聊聊”标题；
2. 右侧资料卡仍显示 NPC 名称、肖像和好感度；
3. 现有布局和完整 C# 测试保持通过；
4. 真实引擎视觉截图中左上角不再出现与边框粘连的标题或状态文字。

## 非目标

- 不改变聊天菜单整体尺寸、按钮文字或 NPC 资料卡样式；
- 不修改 IME、Bridge、NPC 位置和房屋入口逻辑；
- 不为此问题引入新的字体、贴图或 Windows 专用渲染路径。
