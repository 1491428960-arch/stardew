# Dialogue Lab 三页 UI 统一设计

## 目标

让 `/test`、`/test/chat` 和 `/raw` 看起来属于同一个 Stardew AI NPC 工作台，同时保留三个页面现有的信息布局和交互行为。

## 设计

- 统一使用米白工作区背景、森林绿主色、棕色正文、金色提示色和相同的圆角、边框、阴影、字体层级。
- 三页顶部都使用相同的品牌栏和工作台导航，包含“测试例浏览”“单次聊天”“原始对白”三个入口，并为当前页面标记 `aria-current="page"`。
- 通过 `DIALOGUE_LAB_SHARED_UI_CSS` 注入一套共享主题 CSS，页面自己的布局 CSS 继续保留，只覆盖主题、顶栏、导航、按钮和通用状态样式。
- `/test` 继续使用测试例导航 / 详情 / 覆盖三栏；`/test/chat` 继续使用场景 / 对话 / 诊断三栏；`/raw` 继续使用筛选 / 代表对白 / 全部原文布局。
- 保留现有窄屏规则，不引入新的滚动层，不改变聊天记录、本地会话、案例接口或原始对白接口。

## 测试与验收

- 页面契约测试确认三个路由都包含同一版本的主题标记、三个导航入口、当前页标记和共享导航类名。
- 原有页面/API 测试继续通过。
- 三段嵌入 JavaScript 继续通过 Node 语法检查。
- Bridge 全量 pytest 通过。
- 重启 Bridge 后三个路由返回 200，健康接口保持 `provider=local`；页面实际展示以当前内置浏览器为最终人工检查入口。
