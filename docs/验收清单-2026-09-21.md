## 二、怎么部署（二选一）

**前提：先关掉游戏**（DLL 被占用时复制会失败）。

### 路线 A：用隔离档验收（推荐，**不碰你的正式存档**）

```powershell
cd E:\workspace\projects\stardew-ai-npc\.worktrees\story-memory
dotnet build smapi\StardewAI.NPC.csproj -p:GamePath="D:\sbeam\steamapps\common\Stardew Valley" -p:EnableModDeploy=false -p:EnableModZip=false
pwsh -NoProfile -File scripts\start_fast_test.ps1
```

它会装配 `Mods-AI-FastTest` 并在测试存档上启动 —— 界面和正式环境完全一样，但**不会写你的存档**。

### 路线 B：装进正式 Mods（用你自己的存档）

```powershell
# 1) 备份（万一要回滚）
Copy-Item 'D:\sbeam\steamapps\common\Stardew Valley\Mods\StardewAI.NPC' `
          'D:\sbeam\steamapps\common\Stardew Valley\Mods\StardewAI.NPC.bak-20260921' -Recurse

# 2) 复制新 DLL（只这一个文件，manifest 没改）
Copy-Item 'E:\workspace\projects\stardew-ai-npc\.worktrees\story-memory\smapi\bin\Debug\net6.0\StardewAI.NPC.dll' `
          'D:\sbeam\steamapps\common\Stardew Valley\Mods\StardewAI.NPC\StardewAI.NPC.dll' -Force
```

**回滚**：把备份目录换回来即可（或删掉新 DLL、恢复旧的那份）。
